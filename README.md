# Custom Alert Stream (Saweria)

Koleksi **47 template Custom Alert Saweria** berbasis HTML & CSS murni yang responsif, ringan, dan siap pakai untuk OBS Studio / Browser Source.

## URL Galeri Template

- **Galeri Lokal (Live Server / HTTP):** [http://localhost:5500/index.html](http://localhost:5500/index.html) (atau buka [index.html](./index.html))
- **GitHub Pages (jika sudah di-deploy):** `https://<username>.github.io/<nama-repo>/`

> **Catatan:** Jalankan melalui **Live Server** (VS Code) atau HTTP server lokal (`npx serve .` / `python -m http.server`) agar fitur baca & salin **Source Code** otomatis berjalan lancar.

---

## Fitur Utama

- **47 Tema Pilihan:** Anime, Game, Cute/Sanrio, Mobil & Sport, hingga Aesthetic Jepang & Lofi.
- **Saweria-Safe CSS:** Tanpa komentar, tanpa selektor global (`*`/`body`), ringkas di bawah batas karakter Saweria.
- **Preview Interaktif Single Page:** Uji nama donatur, nominal (format `Rp`), dan pesan (Singkat / Panjang / Tanpa Pesan) secara langsung.
- **Toggle `Border: ON / OFF` Otomatis:** Mematikan atau menyalakan border & outline sekaligus otomatis memperbarui kode CSS yang siap disalin.
- **Galeri Cepat & Ringan:** Dilengkapi pencarian, filter kategori, dan pagination (9 template per halaman).

## Struktur Direktori

```text
Custom Alert Stream/
├── index.html                  # Halaman utama galeri seluruh template
├── README.md                   # Dokumentasi proyek
└── Templates/
    ├── alert1/
    │   ├── index.html      # Halaman preview interaktif + Source Code
    │   ├── packs.html      # Kode HTML siap tempel ke Saweria
    │   └── style.css       # Kode CSS siap tempel ke Saweria
    ├── alert2/
    └── ... sampai alert47/
```

---

## Cara Menggunakan di Saweria

1. Jalankan proyek menggunakan Live Server lalu buka **Galeri Utama** ([index.html](./index.html)).
2. Pilih tema alert yang diinginkan dan klik **Buka**.
3. Uji tampilan donatur, nominal, pesan, serta pilih **`Border: ON`** atau **`Border: OFF`**.
4. Pada panel **Source Code** di bagian bawah:
   - Klik **Salin HTML** lalu tempel ke kolom **HTML** di dashboard Custom Overlay Saweria.
   - Klik **Salin CSS** lalu tempel ke kolom **CSS** di dashboard Custom Overlay Saweria.
5. Klik **Simpan Tampilan** di Saweria.
